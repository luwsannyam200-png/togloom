# Цайны цаг

Завсарлагын богино тоглоомууд. Утас болон notebook дээр браузераар тоглоно. Юу ч суулгах шаардлагагүй.

| Тоглоом | Файл | Удирдлага |
|---|---|---|
| Цэс (бүх тоглоом) | `index.html` | — |
| Болжмор — хадны завсраар нисэх | `bolzhmor.html` | Товших эсвэл Space |
| Карьерын зам — чулуу, том машинаас зайлсхийх | `karier.html` | Дэлгэцийн зүүн/баруун тал эсвэл ← → |
| Таавар 3×3 — 1–8 дугаарыг дараалуулах | `taavar.html` | Товших эсвэл сум |
| Мэдлэгийн сорил — 10 асуулт, 15 секунд | `soril.html` | Товших эсвэл 1–4 товч |
| Шатар — компьютертэй (3 түвшин) эсвэл хоёулаа нэг дэлгэц дээр | `shatar.html` | Дүрс дээр, дараа нь очих нүдэн дээр товших (чирч ч болно) |

`app.css`, `app.js` нь бүх хуудасны нийтлэг загвар, код юм. Хуудаснууд эдгээргүйгээр ажиллахгүй.

## Хоёр хувилбар

- **GitHub Pages дээрх энэ хувилбар.** Ганцаараа тоглоход зориулсан. Таны амжилт зөвхөн өөрийн чинь төхөөрөмж дээр хадгалагдана.
- **Claude дээрх хувилбар (Artifact линк).** Энэ хувилбарт **нийтийн онооны самбар**, багаараа зэрэг тоглох **«Хамтдаа сорил»** (өөрийн асуултаар тэмцээн зохиох), **онлайн шатар**, **шатрын тэмцээн** ажиллана. Энэ линкийг багийнхандаа шууд өгнө.

## Шинэчлэх

Тоглоом өөрчлөгдөх бүрт ямар файлыг дахин upload хийхийг хэлж өгнө. Ихэнхдээ зөвхөн `app.js` солигдоно. Repo дээр **Add file → Upload files** гээд тэр файлыг чирж оруулаад **Commit changes** дарна. Ижил нэртэй файл шинээр солигдоно.

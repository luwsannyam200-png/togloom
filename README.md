| Тоглоом | Файл | Удирдлага |
|---|---|---|
| Цэс (бүх тоглоом, онооны самбар, өрөө) | `index.html` | — |
| Болжмор — хадны завсраар нисэх | `bolzhmor.html` | Товших эсвэл Space |
| Карьерын зам — чулуу, том машинаас зайлсхийх | `karier.html` | Дэлгэцийн зүүн/баруун тал эсвэл ← → |
| Таавар 3×3 — 1–8 дугаарыг дараалуулах | `taavar.html` | Товших эсвэл сум |
| Мэдлэгийн сорил — 10 асуулт, 15 секунд | `soril.html` | Товших эсвэл 1–4 товч |
| Шатар — компьютер, хоёулаа, онлайн, тэмцээн | `shatar.html` | Дүрс дээр, дараа нь очих нүдэн дээр товших (чирч ч болно) |
| CS2 академи — асуулт, газрын зургаар таах, utility lineup | `cs2.html` | Товших |

## Хамтдаа тоглох

Анх нээхэд нэрээ бичнэ. Хүсвэл зураг, өнгө, дуртай тоглоом, төлөвөө сонгоно. Бүртгэл, нууц үг хэрэггүй. Төхөөрөмж тань санана.

- **Онооны самбар.** Тоглоом бүрийн шилдэг оноо бүх хүнд харагдана: Өнөөдөр, Энэ 7 хоног, Бүх цаг гэж шүүнэ. Нэр дээр дарахад тухайн хүний профайл гарна. Өдөр бүр нэг тоглоом «👑 Өнөөдрийн тоглоом» болно.
- **Баг.** Профайлдаа багийн нэрээ бичвэл ижил нэртэй хүмүүс нэг баг болж «👥 Баг» самбарт хамтдаа өрсөлдөнө.
- **Зарлал.** Тэмцээн болон бусад зарлалаа нийтэлнэ. Өрөө, шатрын тэмцээн рүү холбоос хийж болно.
- **Өрөө.** «Өрөө нээх» дарахад код, холбоос гарна. Холбоосыг багийнхандаа явуулна. Өрөө нээсэн хүн тоглоом, хугацаагаа сонгоод тэмцээн эхлүүлнэ. Тэр хугацаанд хамгийн өндөр оноо авсан нь ялна. Өрөөнөөс бүх тоглоомыг өрөөнийхөнтэйгээ тоглоно.
- **Хамтдаа сорил.** Бүгд нэг асуултад зэрэг хариулна. Өөрийн асуултаар тэмцээн зохиож болно.
- **Шатар.** Онлайнаар хоёулаа тоглох, тойргийн тэмцээн зохиох боломжтой.
- **Хэлэх үг.** Хамт олон, найз нөхөддөө хэлэх үгээ нэргүйгээр үлдээнэ. Хэн бичсэн нь хадгалагдахгүй. Самбарын эзэн зөвшөөрсний дараа самбарт гарна.
- Өрөө, шатрын тэмцээн **кодгүй** (жагсаалтад харагдана) эсвэл **кодтой** (зөвхөн кодоор) байж болно.

Онлайн боломжууд `firebase-config.js` тохируулсан үед ажиллана. Тохируулаагүй үед тоглоомууд ганцаараа тоглох горимоор ажиллана.

# Цайны цаг

Завсарлагын богино тоглоомууд. Утас болон notebook дээр браузераар тоглоно. Юу ч суулгах шаардлагагүй.

| Тоглоом | Файл | Удирдлага |
|---|---|---|
| Цэс (бүх тоглоом, онооны самбар, өрөө) | `index.html` | — |
| Болжмор — хадны завсраар нисэх | `bolzhmor.html` | Товших эсвэл Space |
| Карьерын зам — чулуу, том машинаас зайлсхийх | `karier.html` | Дэлгэцийн зүүн/баруун тал эсвэл ← → |
| Таавар 3×3 — 1–8 дугаарыг дараалуулах | `taavar.html` | Товших эсвэл сум |
| Мэдлэгийн сорил — 10 асуулт, 15 секунд | `soril.html` | Товших эсвэл 1–4 товч |
| Шатар — компьютер, хоёулаа, онлайн, тэмцээн | `shatar.html` | Дүрс дээр, дараа нь очих нүдэн дээр товших (чирч ч болно) |
| Буудлага — 3D онлайн, бүгд бие биенийхээ эсрэг | `buudlaga.html` | Notebook: WASD, хулгана, зүүн товч, Space. Утас: зүүн тал явах, баруун тал харах, ГАЛ, ҮСЭР |

## Хамтдаа тоглох

Анх нээхэд нэрээ бичнэ. Бүртгэл, нууц үг хэрэггүй. Төхөөрөмж нэрийг тань санана.

- **Онооны самбар.** Тоглоом бүрийн шилдэг оноо бүх хүнд харагдана.
- **Өрөө.** «Өрөө нээх» дарахад код, холбоос гарна. Холбоосыг багийнхандаа явуулна. Өрөө нээсэн хүн тоглоом, хугацаагаа сонгоод тэмцээн эхлүүлнэ. Тэр хугацаанд хамгийн өндөр оноо авсан нь ялна.
- **Хамтдаа сорил.** Бүгд нэг асуултад зэрэг хариулна. Өөрийн асуултаар тэмцээн зохиож болно.
- **Шатар.** Онлайнаар хоёулаа тоглох, тойргийн тэмцээн зохиох боломжтой.
- **Хэлэх үг.** Хамт олон, найз нөхөддөө хэлэх үгээ нэргүйгээр үлдээнэ. Хэн бичсэн нь хадгалагдахгүй.
- Өрөө, шатрын тэмцээн **кодгүй** (жагсаалтад харагдана) эсвэл **кодтой** (зөвхөн кодоор) байж болно.

Онлайн боломжууд `firebase-config.js` тохируулсан үед ажиллана. Тохируулаагүй үед тоглоомууд ганцаараа тоглох горимоор ажиллана.
